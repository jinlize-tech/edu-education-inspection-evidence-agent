# 年检与专项检查证据包领域指南

## 业务问题

年检、专项检查或主管部门抽查来临时，证据散落在不同部门，常见问题是找不到、版本不一致或责任不明。

## 产品解决方案

按检查主题建立证据目录，逐项核验制度、记录、资质、合同、财务与整改闭环，编排补证任务。

## 输入质量要求

| 字段 | 名称 | 必填 | 质量要求 |
|---|---|---|---|
| `inspection_notice` | 检查通知或要求 | 是 | 须保留来源和日期 |
| `campus_scope` | 检查校区范围 | 是 | 单校区或多校区 |
| `evidence_inventory` | 现有证据材料清单 | 是 | 类别、文件名、版本、责任人、日期 |
| `responsible_roles` | 责任角色 | 是 | 材料补充、复核和提交责任人 |
| `deadline` | 提交截止日期 | 是 | ISO 日期或用户确认的日期口径 |

## 证据判断

- 用户原文优先于模型推断。
- 外部政策或公开事实应记录标题、发布机构、发布日期、URL、访问日期和适用范围。
- 无法核验时标记`EVIDENCE_UNVERIFIED`，不补造来源。
- 数据冲突必须并列展示，并说明对结论的影响。

## 人工复核

校区负责人/材料责任部门应确认：真实材料、原件、签批、责任人与对外提交版本。未经确认的内容只能作为草案。

## 主要风险

不能替代主管部门要求或法律判断；必须由有权限人员确认原件和签批；不得生成虚假材料。
